# 今日观察交易日对齐与图表修复设计

## 目标

修复今日观察在非交易日、聚合接口部分返回和历史序列缺失场景下的四类问题：

- 周末或休市日必须展示最近完整交易日数据，不得用页面生成日期冒充市场日期。
- 指数、市场广度、涨跌停、成交额和行业数据必须暴露各自市场日期，并检测跨日混合。
- 市场总览或行业轮动缺失时，前端必须独立补拉对应模块，不能长期保留空白占位。
- 成交活跃度柱状图必须清晰可读；行业折线必须来自真实交易日历史，不得使用两点反推序列。

## 已确认根因

1. 前端在 `marketOverview` 缺失时使用 `generatedAt` 的自然日作为快照日期，周六因此可能显示周六。
2. 后端聚合请求设置两秒等待上限并允许保存部分响应；前端只对成交活跃度做缺失补拉。
3. 成交柱高度使用百分比，但柱子父元素没有确定绘图区高度，百分比高度退化为最小高度。
4. 行业轮动把 `fiveDayChangePct` 固定为 `None`，并用当日涨跌幅反推两个价格点，不是真实历史。
5. 聚合响应只有生成时间，没有模块日期清单和对齐状态，旧行业缓存与新市场广度可以被无提示混合。

## 数据契约

今日聚合响应增加兼容字段：

```json
{
  "asOfMarketDate": "2026-07-24",
  "generatedAt": "2026-07-25T10:08:18+00:00",
  "dateAlignment": {
    "status": "aligned",
    "anchorMarketDate": "2026-07-24",
    "moduleMarketDates": {
      "indices": "2026-07-24",
      "marketOverview": "2026-07-24",
      "industryRotation": "2026-07-24",
      "tradingActivity": "2026-07-24",
      "limits": "2026-07-24"
    },
    "mismatchedModules": []
  }
}
```

规则：

- `generatedAt` 只表示处理时间，不参与市场日期选择。
- 市场时间统一转换为 `Asia/Shanghai` 后提取交易日。
- `marketOverview.marketDate` 优先作为锚点；缺失时使用可用模块日期的众数，不能使用自然日兜底。
- 所有模块返回自己的 `marketDate`、`fetchedAt` 和 `source`。
- 日期不同的模块列入 `mismatchedModules`。聚合可以返回数据，但状态不得写成“数据已更新”。
- 周末若所有模块最新日期为周五，状态为 `aligned`，标题显示“数据截止 周五日期（最近交易日）”。

## 行业真实历史

沿用现有东方财富板块代码，不创建第二套行业体系。

- 板块排名结果保留 `code`。
- 数据提供层按板块代码获取最近五个已完成交易日的日线收盘值和日期。
- 单板块历史请求设置明确超时，使用既有数据库缓存；最多三个并发请求。
- `trend` 至少包含三个真实交易日点才可绘制。
- `fiveDayChangePct` 使用序列首尾收盘值确定性计算。
- 返回 `trendMarketDates`、`trendStatus` 和 `historySource`。
- 历史不足或数据源失败时返回 `trendStatus=unavailable`，前端显示“历史走势补齐中”，不绘制反推折线，不显示 `0.00%`。

聚合首屏优先使用已有历史缓存，保持快速返回；前端发现趋势不足时调用现有行业轮动接口补拉真实历史。

## 前端补拉和状态

`QSReloadTodayDashboard` 在聚合返回后检查以下模块：

- `marketOverview`
- `industryRotation`
- `riseFallDistribution`
- `hotThemes`
- `tradingActivity`
- `sectorFundFlow`

缺失、模块错误或行业趋势不足时，只补拉对应接口。所有补拉使用 `Promise.allSettled`，单模块失败不影响其他卡片。

页面标题区分别显示：

- 数据截止：实际交易日。
- 页面更新：`generatedAt` 的处理时间。
- 对齐异常：列出仍跨日的模块。

各卡片保留自身数据日期，避免用户把抓取时间误认为行情时间。

## 图表

成交活跃度：

- 柱图拆分为固定高度的绘图区、数值标签和日期标签。
- 纵轴保持零基准，最高柱使用绘图区约 88% 高度。
- 最低可见高度只用于非零值的视觉可访问性，不改变数值标签。
- 最新交易日使用主题蓝，同时显示完整日期提示。

行业轮动：

- 仅绘制真实历史点。
- 画布宽度提高，至少三点时显示折线。
- 五日数据不足时显示文本状态，不用零值替代。

## 错误处理

- 聚合部分成功时返回已有模块和 `moduleErrors`。
- 前端补拉失败后卡片显示模块级错误及重试入口。
- 日期不一致不静默吞掉，也不把旧数据重标为新日期。
- 外部历史接口失败时使用仍在有效期内的缓存；没有缓存则明确不可用。

## 测试

后端测试覆盖：

- 周六生成响应时，`asOfMarketDate` 仍为周五。
- 处理时间不进入交易日选择。
- 跨日模块被标记为 `mixed`。
- 真实五日行业序列计算正确。
- 历史不足时不生成两点反推趋势。

前端契约测试覆盖：

- 缺失市场总览会触发独立补拉。
- 行业趋势不足会触发历史补拉。
- 页面不再从 `generatedAt` 推导市场日期。
- 柱状图具有固定绘图区。
- `fiveDayChangePct=null` 不显示为 `0.00%`。

浏览器验证使用 1440×900 和 390×844 两种尺寸，并检查无横向溢出、柱图可读、市场总览有值、行业折线可见及所有日期一致。

## 兼容与回滚

- 只增加响应字段，保留原字段，不破坏现有调用方。
- 不修改数据库表结构。
- 新行业历史缓存可随时失效重建。
- 回滚时旧前端可以忽略新增字段；旧后端字段仍保持兼容。
