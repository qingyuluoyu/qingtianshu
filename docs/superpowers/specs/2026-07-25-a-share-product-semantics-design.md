# A 股产品语义与真实数据接通设计

## 目标和边界

本次把高保真静态页面从展示型原型收敛为 A 股散户研究工作台。范围包括前端页面、前端领域契约、fixture、既有接口适配，以及为统一既有评分数据所需的最小后端适配和测试。不接入支付、券商、会员、外部自建 API 或美股。

生产页面只消费已有服务端返回的数据。开发 fixture 必须隔离并显式标注，接口失败时不回退为看似实时的静态行情、评分或用户资产。

## 已核实的数据基础

`GET /api/v1/stocks/{symbol}/score-card` 已限制为 A 股；`GET /api/v1/stocks/{symbol}/industry-comparison` 已返回同一财报期的行业截面、样本数、覆盖率、指标方向和评分状态。实际请求 `300750.SZ` 返回的财报期为 `2025-12-31`，同行样本为 103 家，估值截面日期为 `2026-07-24`。

当前行业接口的五个因子是“成长性、估值水平、盈利能力、财务稳健性、经营效率”。它不能被直接改名成产品要求的五个维度；当前接口也没有对“趋势状态、风险水平”给出产品可解释的分值。因此，继续只改前端会制造错误金融口径。

## 评分契约与方法迁移

以版本化的适配契约替换页面对旧因子的直接依赖，固定输出：经营质量、成长能力、估值水平、趋势状态、风险水平。旧 `sw2_five_factor_comparison_v1` 保留为兼容输出，不与新页面混用；新页面仅使用新契约，并显示 `method` 和 `formulaVersion`。

新契约只复用当前已接通的确定性原始指标与 K 线：

* 经营质量：盈利能力和经营效率的已计算指标；
* 成长能力：既有增长因子；
* 估值水平：既有 PE/PB/PS 历史及同业反向分位；
* 趋势状态：基于已接通复权日 K 线的均线位置与区间收益，标明自身时间序列口径；
* 风险水平：既有财务稳健性和盈利波动等风险指标，方向为分数越高风险越低。

这不是同时引入第二套面向消费者的模型：页面只展示新的产品标准契约。每个维度必须返回数据截止时间、财报期、行业样本数（趋势为“自身时间序列，不适用同行样本”）、覆盖率、指标方向、缺失状态、可用状态。评分函数必须拒绝不同财报期的横向比较，不能产生部分对齐的数值。

## 领域对象与状态

前端通过独立适配类型表达：

* `WatchlistItem`：优先级、关注原因、催化条件、失效条件、跟踪频率；
* `ResearchCase`：研究状态、问题、证据快照、结论、有效期；
* `Position`：模拟/实盘、数量、成本、市值、未实现盈亏；
* `Trade`：方向、成交时间、价格、数量、费用、已实现盈亏。

这些对象不得共享表示生命周期的 `status` 字段。关注项可同时拥有研究案例和持仓；已清仓仅属于持仓/交易历史。现有只支持关注项的服务端接口仍可继续保存关注字段；没有 Position/Trade 持久化接口时，生产页面显示明确的空状态和不可用入口，不在浏览器伪造用户资产。

## 页面结构

首页首屏重排为：我的持仓风险、我的关注变化、计划条件触发、待验证事项、待复盘交易、市场环境摘要；通用行情卡片下移。关注页的新增表单只创建关注项，不再接收买入价、数量和卖出价；列表拆分显示关注、研究和持仓状态，并在现有能力边界内提供模拟/实盘记录入口说明。

AI 研究的章节改为公司与财务、行业与竞争、估值与预期、事件与催化、风险与反证。它不再称为评分维度，也不向消费者暴露 run、后台聚合、模型证据聚类等内部名称。

复盘按平仓交易计算胜率与已实现盈亏；持仓只贡献未实现盈亏。净盈亏 = 已实现盈亏 + 未实现盈亏 - 交易费用；任何未平仓交易不得计入胜率。

## A 股和公开能力边界

搜索、评分、关注、研究和复盘统一拒绝非 `.SS`、`.SZ`、`.BJ` 标识。清除 NVDA、美股、美元与美元行业 fixture；指数使用上证指数、深证成指、创业板指、科创50。页面使用文字和图标/色彩共同表达涨跌、可用性和风险。

隐藏支付订单草稿、会员、自建 API、未接通数据源消费者展示以及其他仅供开发人员理解的文字。数据展示统一区分数据来源、原文发布时间、采集时间、处理时间和数据截止时间。

## 验证与兼容

先为评分适配和复盘计算补失败测试，再实现。执行仓库真实存在的测试、构建、lint、typecheck 命令；若项目不存在相应工具，记录“无项目脚本”而不伪造执行。使用浏览器在 1440x900 和 390x844 检查页面，且以真实 API 响应验证评分报告期、样本和覆盖率。

方法迁移采用新增响应字段和页面适配的兼容策略，不删除旧 API 字段。若新评分适配不能从真实输入得到完整、同口径结果，接口明确返回不可用原因，页面不显示伪精确数值或“暂不评分”。
