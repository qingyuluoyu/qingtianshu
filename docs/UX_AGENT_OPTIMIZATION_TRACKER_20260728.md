## 3. 同事设计吸收原则

优先吸收：

1. `qs-charts.js` 的全量均线计算后切片、拖拽、缩放、十字光标、OHLCV和成交量联动。
2. 高保真页面的任务导向标题、留白、清晰分组、主次按钮和详情渐进披露。
3. 研究任务状态机的租约、重试、取消和恢复思想，但只映射到当前 PostgreSQL durable worker。

明确不吸收：

1. SQLite 平行数据库、第二套持仓或交易流水。
2. 黑盒综合投资评分、目标价、胜率和确定性买卖结论。
3. 静态演示数字、没有真实接口或浏览器证据的设计稿功能。
