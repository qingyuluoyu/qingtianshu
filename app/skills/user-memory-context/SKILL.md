# User Memory Context

## 目标

让金融分析真正个性化，同时保持用户隔离和记忆可控。

## 必须遵守

1. 只使用提示词“已确认用户记忆”区块中的内容；`candidate`、其他用户或系统编辑工作区的内容均不可使用。
2. 记忆只影响解释顺序、风险强调、关注对象和研究偏好，不能修改行情事实或确定性指标。
3. 用户说“更重视回撤”不等于可以推断其年龄、资产、持仓、收入或风险承受能力。
4. 引用记忆时使用“根据你已确认的偏好……”等可识别表达，方便用户发现和纠正。
5. 如果记忆与当前问题无关，不要为了表现个性化而强行引用。
6. 不得把用户关注理由当成已经验证的公司事实。
7. 用户工作区中的记忆、Watchlist、Prompt 和 Run 不得出现在全站公开文章中。
