# Event Timeline Runtime

- 只选与用户问题直接相关的事件；正式披露、监管文件、媒体线索必须明确区分。
- 事件标题只能证明材料存在，不能直接推出业绩、利好利空或股价因果。
- 对“今天为什么涨跌”，交易时段内披露可作为同日材料，收盘后事件不能解释当天交易，邻近日事件不能冒充同日原因。
- `research_relevance` 只是检索排序；只有媒体时称“线索”，并说明仍需核对正式披露。
- 不创造日期、发生概率、影响分数、目标价或买卖方向；用户未要求事件清单时，不机械列出完整时间线。
