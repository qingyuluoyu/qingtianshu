# A股任意股票研究 Skill — 通用运行规范

版本：7.0.0

## 1. 适用范围

本 Skill 面向沪深北交易所全部 A 股上市公司，不以某一家制造业、科技股或成长股为默认样本。执行前必须先识别公司的会计模型、经营模式、生命周期、业务结构和当前事件，再选择研究模块。

允许覆盖：

- 主板、创业板、科创板、北交所；
- 正常上市、ST/*ST、重组、困境反转、持续亏损、新上市公司；
- 制造、消费、软件、医药、资源、公共事业、交通、建筑、房地产、银行、保险、券商、控股平台等公司；
- 单一主业和多元化集团。

## 2. 核心目标

报告面向交易员和研究员，必须形成完整研究闭环：

1. 识别研究对象和当前最重要的问题；
2. 选择与公司类型匹配的数据、指标和研究方法；
3. 解释最新事实、历史趋势和边际变化；
4. 建立变量之间的传导关系；
5. 区分已披露事实、系统计算、管理层表述、外部预测和系统推断；
6. 给出支持证据、反向证据、未验证事项、下一验证节点和失效条件。

禁止把搜索结果、F10资料、指标清单或统一模板直接拼成报告。

## 4. 通用路由：先分类，再研究

执行报告前生成 `company_routing`，至少包括以下字段。

### 4.1 会计与经营模型 `business_archetype`

从下列类型中选择一项主类型，可附加一项次类型：

- `general_industrial_service`：制造、消费品、一般服务、硬件；
- `bank`：商业银行；
- `insurance`：寿险、财险、保险集团；
- `securities`：证券公司、期货及综合金融服务；
- `real_estate`：房地产开发、商业地产；
- `construction_project`：建筑、工程、系统集成、项目制业务；
- `utility_transport`：电力、燃气、水务、公路、港口、机场、铁路、航运；
- `resource_cyclical`：煤炭、油气、金属、化工、建材、农产品等强周期；
- `pharma_biotech`：成熟制药、创新药、生物科技、医疗器械；
- `software_platform`：软件、互联网平台、订阅及数字服务；
- `holding_asset`：投资控股、资产运营、主要价值来自参控股公司；
- `special_situation`：ST、重整、资产注入、重大重组、壳价值或经营模式正在重构。

不能仅使用证监会行业名称完成分类。需要结合收入、利润、资产和现金流来源判断。

### 4.2 生命周期 `life_cycle`

- `early_loss_making`：早期或持续亏损；
- `high_growth`：高速扩张；
- `mature_stable`：成熟稳定；
- `cyclical_up` / `cyclical_down`：周期上行或下行；
- `turnaround`：经营修复；
- `distressed`：流动性、净资产或持续经营压力；
- `post_merger`：重大并购后的整合期。

### 4.3 业务结构 `segment_structure`

- `single_core`：单一核心业务；
- `multi_segment_related`：相关多元化；
- `conglomerate`：跨行业集团；
- `asset_heavy_platform`：资产运营平台。

### 4.4 事件重要性 `event_materiality`

对分析截止日前的最新事件评分：

- `material`：财报、业绩预告、重大订单、资产重组、监管处罚、重大技术/政策/价格变化，足以改变核心假设；
- `relevant`：提供增量证据，但不足以重建主要模型；
- `immaterial`：普通会议、产品宣传、小额事项或与盈利无直接关系的新闻。

`report_mode=auto` 时：

- 仅 `material` 事件触发更新报告；
- `relevant` 事件融入深度报告；
- `immaterial` 事件不得主导报告标题和结构；
- 近期无重大事件时输出公司/维度深度研究，不强行写“点评”。

## 5. 数据与证据等级

### 5.1 Claim type

- `reported_fact`：正式公告、财报或监管披露；
- `structured_fact`：Tushare 等结构化数据；
- `management_statement`：管理层、业绩说明会、投资者关系记录；
- `external_estimate`：券商、行业机构、一致预期或第三方预测；
- `system_calculation`：公式及输入可追溯的计算；
- `system_inference`：多项证据形成的推断；
- `unverified_information`：尚未可靠确认的信息。

### 5.2 Evidence grade

- `A1`：交易所、监管机构、公司正式公告和定期报告；
- `A2`：政府、统计机构、客户或供应商正式披露；
- `B1`：公司官网、投资者关系活动记录、正式演示材料；
- `B2`：行业协会、权威数据库和一手产业资料；
- `C1`：券商研报和机构预测；
- `C2`：高质量财经媒体；
- `D`：普通媒体、转载、搜索摘要；
- `U`：来源不明。

核心结论不得只依赖 D/U。搜索摘要只能用于定位原文。

## 6. 数据质量与降级机制

每项数据标记：`available`、`missing`、`conflicted`、`stale`、`not_applicable`。

报告状态分为：

- `full`：核心数据完整，可建立主要模型；
- `constrained`：存在缺口，仍可输出受限结论；
- `blocked`：缺少本维度必要数据，禁止继续生成伪分析。

必须说明缺口对哪些结论造成限制。不得通过网页传闻、行业均值或其他公司数据补造目标公司的缺失数字。

通用校验：

- 公告和数据不得晚于分析截止日；
- 年报、半年报、累计季度、单季度和预测口径不得混用；
- 修订公告优先于原公告；
- 元、万元、亿元、股、手等单位先统一再计算；
- 合并口径、母公司口径、归母和少数股东权益必须区分；
- 并购、增发、转股、除权和会计政策变化需要做可比性调整；
- 结论使用的数据必须可追溯到 `source_id` 或 `calculation_id`。

## 7. 写作和组织方式

报告以连贯研究论证为主，不要求机械填满固定章节。根据公司类型和研究问题动态选择模块。

每个重要段落遵循：

> 事实与数据 → 形成机制 → 对本维度的影响 → 证据限制或反向条件

表格用于比较、趋势、预测、敏感性和风险映射。每张表必须有标题、单位、口径、来源和正文解读。不得用大量状态标签表替代研究论证。

禁止：

- “不是……而是……”等口号式二元对立；
- “一句话看懂”“真正的问题只有一个”“全面爆发”等营销表达；
- 概念堆砌和重复结论；
- 无证据的主力行为、财务造假或违法定性；
- 买入、卖出、保证收益和确定性目标价；
- 因数据不足而输出看似精确的数字。

## 8. 图文输出

模型输出 `dimension_report.json`，渲染层生成 HTML、PDF、DOCX。

推荐结构：

```json
{
  "meta": {},
  "company_routing": {},
  "data_quality": {},
  "research_thesis": {},
  "blocks": [],
  "tables": [],
  "charts": [],
  "conclusion": {},
  "sources": [],
  "limitations": []
}
```

`blocks` 使用灵活的叙事块，不要求固定章节数量。图表只引用已有数据：

- `chart_id`
- `chart_type`
- `title`
- `research_question`
- `data_ref`
- `series`
- `unit`
- `time_range`
- `source_ids`
- `notes`

无可靠数据时不绘图。

## 9. 结论要求

结论需要包含：

- 当前判断及适用范围；
- 最重要的支持证据；
- 最重要的反向证据；
- 未验证信息；
- 下一验证节点；
- 上调条件；
- 下调或失效条件；
- 数据限制。

# A股任意股票基本面深度研究 Skill

维度标识：`fundamental`

## 1. 任务

围绕公司的盈利来源、经营变化、财务质量和未来可验证变量，形成适配公司类型的基本面研报。报告需要回答：

1. 收入、利润、现金流和资本回报由哪些业务或资产产生；
2. 最新重大信息改变了哪些经营假设；
3. 表观增长分别来自同口径经营、价格、销量、产品结构、周期、并表、会计口径或一次性项目中的哪些部分；
4. 盈利质量和资产负债状况是否支持当前利润；
5. 后续盈利取决于哪些可观测变量；
6. 哪些证据支持判断，哪些证据限制判断。

## 2. 基本数据准入

通用公司建议取得最近 3—5 年及最新一期：利润表、资产负债表、现金流、财务指标、主营构成、预告/快报、年报和最新季报正文。

数据不足时：

- 主营构成缺失：只做合并口径，不构造分业务利润；
- 一致预期缺失：不使用“超预期”，改用历史、公司指引和系统情景；
- 只有业绩预告：只分析预告区间、同比基数、扣非差异和公司披露原因；
- 并购标的单体数据缺失：不得把合并增长全部归因于标的；
- 金融机构缺少监管指标：输出受限报告，不套用制造业现金流指标；
- 关键报表冲突且无法确定正式口径：`blocked`。

## 3. 自动选择基本面模型

### 3.1 一般制造、消费、硬件和服务

研究主线：

- 收入：销量/客户数 × 价格/客单价 × 产品与地区结构；
- 毛利：售价、材料、人工、良率、产能利用率、渠道和产品组合；
- 费用：销售、管理、研发、财务费用及经营杠杆；
- 现金流：应收、存货、预付、应付、合同负债和资本开支；
- 资本回报：ROIC、ROE、自由现金流和增量资本效率。

### 3.2 银行

不得使用一般工业企业毛利率和经营现金流框架。重点分析：

- 生息资产规模与结构；
- 净息差、资产收益率和负债成本；
- 手续费及其他非息收入；
- 不良率、关注类贷款、逾期、拨备覆盖率；
- 信用成本和减值；
- 核心一级资本充足率、资本消耗和分红能力；
- 对公、零售、按揭、信用卡、区域和行业集中度。

基本盈利桥：平均生息资产 × 净息差 + 非息收入 − 业务管理费 − 信用减值 − 税费。

### 3.3 保险

重点分析：

- 保费、新单保费、NBV/VNB、价值率；
- 代理人、银保、团险等渠道；
- 赔付率、费用率、综合成本率；
- 投资资产配置、净投资收益率和总投资收益率；
- 准备金假设、折现率和会计准则影响；
- 偿付能力、资本补充和分红。

财险和寿险必须分开建模。

### 3.4 证券公司

重点分析：

- 经纪业务与市场日均成交额；
- 投行业务储备、承销规模和发行节奏；
- 资管规模、费率和主动管理占比；
- 自营投资、衍生品和方向风险；
- 融资融券、股票质押、利息净收入；
- 杠杆、净资本和风险覆盖率。

### 3.5 房地产

重点分析：

- 合同销售、销售均价、回款率；
- 结算收入、结算毛利率和已售未结；
- 土地储备、拿地成本、城市能级；
- 存货、减值、预收款和合同负债；
- 有息债务、现金短债比、融资成本；
- 项目权益比例、少数股东损益和合作项目；
- 商业地产租金及资产价值。

### 3.6 建筑、工程和项目制公司

重点分析：

- 新签订单、在手订单、订单收入覆盖倍数；
- 订单转化周期、项目毛利率；
- 合同资产、应收、工程垫资和回款；
- 合同负债和预收；
- 分包、材料成本、减值和项目退出；
- 经营现金流与利润的长期匹配。

### 3.7 公用事业和交通运输

按业务选择：

- 装机/运力/路产/吞吐能力；
- 利用小时、客运量、货运量、吞吐量；
- 电价、票价、收费标准、运价；
- 煤价、气价、油价等燃料和能源成本；
- 特许经营期限、资本开支、折旧和维修；
- 政府补贴、容量电价、市场化交易和监管机制。

### 3.8 资源和强周期公司

重点分析：

- 商品价格、产销量、品位和产品结构；
- 单位现金成本、完全成本和成本曲线位置；
- 资源储量、矿权年限和采剥比；
- 产能扩张、检修和安全环保限制；
- 库存、长协与现货比例；
- 周期正常化利润和自由现金流。

不得用周期高点利润简单外推。

### 3.9 医药、生物科技和医疗器械

成熟产品与研发管线分开：

- 成熟产品：销量、价格、医保、集采、渠道和竞争；
- 管线：研发阶段、临床终点、入组、审批、商业化、专利期；
- 研发费用、资本化、合作授权和里程碑付款；
- 对早期亏损公司重点分析现金跑道和融资需求；
- 未披露成功率时不得输出伪精确管线价值。

### 3.10 软件、互联网和平台公司

根据披露情况分析：

- 订阅/许可/项目制/广告/交易佣金等收入模式；
- ARR、续费率、付费客户、客单价、合同负债和在手订单；
- 云服务成本、毛利率、获客和销售效率；
- 研发人员、资本化和产品迭代；
- 项目制软件需重点分析验收、回款和合同资产。

### 3.11 投资控股和资产运营平台

重点分析：

- 参控股公司权益利润和现金分红；
- 母公司债务、担保和费用；
- 资产处置和投资收益的可重复性；
- 资产负债表穿透、NAV 和控股折价；
- 关联交易和资金占用。

### 3.12 ST、重整和特殊情形

先处理持续经营、净资产、审计意见、退市规则相关事实、重整进度、债务清偿和主营恢复。不得因资产注入预期直接预测盈利。

## 4. 研究流程

### 4.1 确定研究命题

公司更新报告回答“新增事实改变了什么”；深度报告选择一个可以由数据验证的命题。事件必须经过重要性筛选，普通新闻不触发点评。

### 4.2 重建可比历史

完成：

- 修订报表优先；
- 并购和处置前后口径调整；
- 累计季度推算单季度并标注计算；
- 股本、少数股东、会计准则和汇率口径核对；
- 同比基数异常解释。

### 4.3 业务与利润来源拆解

按收入、毛利润、经营利润、资产占用和现金流的重要性拆分主要业务。多元化公司不得只按收入排序，需要识别利润和资产价值贡献。

每个主要业务至少说明：规模、增长、盈利能力、资本强度、现金流、主要变量和数据缺口。

### 4.4 利润变化桥

根据公司模型选择量化项：

- 量、价、结构；
- 净息差、信用成本；
- 保费、价值率、投资收益；
- 商品价格、产量、单位成本；
- 订单、转化率、项目毛利；
- 并表、处置、投资收益、政府补助、减值、汇率、税率和股份支付。

能够量化时输出桥接表或瀑布图；不能量化时输出“方向—证据—可确认程度—验证方法”，禁止以“结构优化”概括全部变化。

### 4.5 盈利质量与资产负债

选择与模型匹配的指标：

- 一般公司：经营现金流、自由现金流、应收、存货、预付款、合同资产、资本开支、净负债；
- 银行：资产质量、拨备、资本充足率和流动性；
- 保险：偿付能力、准备金和投资资产；
- 地产/建筑：回款、存货、合同负债、项目债务和受限现金；
- 早期公司：现金跑道和融资稀释。

单季度现金流不得脱离季节性和结算周期判断。

### 4.6 预测和情景

仅在数据支持时建立分业务预测。预测需要列出：

- 量、价、客户、产能、订单、利用率或监管变量；
- 收入和利润率假设；
- 非经常性项目是否剔除；
- 与历史、管理层口径和外部预测的差异；
- 谨慎、基准、乐观情景。

数据不足时可只给方向和关键阈值，不得强制输出长期精确利润。

### 4.7 同行比较

先解释可比性。直接同行、产业链参照和估值参照分组。比较指标随公司模型变化，不固定使用毛利率、ROE 或收入增速。

## 5. 输出内容

报告动态选择以下模块：

- 研究命题和本次更新；
- 财务结果与历史趋势；
- 业务和利润来源；
- 利润变化桥；
- 盈利质量与资产负债；
- 公司类型专属指标；
- 预测、情景和外部预期差异；
- 同行比较；
- 反向证据和验证节点。

推荐图表根据公司类型选择：收入利润趋势、业务结构、利润桥、现金流、银行净息差与资产质量、保险NBV与投资收益、周期品价格成本、地产销售结算、项目订单回款、管线时间轴等。

## 6. 验收失败条件

- 对银行使用制造业毛利率和经营现金流结论；
- 对亏损生物科技公司强行预测 PE；
- 对地产只分析营业收入和净利润；
- 对周期公司用高点利润机械年化；
- 对多业务公司将一个行业概念覆盖全部经营；
- 无分业务数据却输出精确业务利润；
- 普通公告触发整篇事件点评；
- 把并表增长写成同口径增长；
- 把投资收益、处置收益或补助当作主营利润。
