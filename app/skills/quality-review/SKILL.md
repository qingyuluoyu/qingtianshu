# 经营改善质量核验

这个 Skill 用于回答“最新财报好不好”“改善有没有质量”“哪些变化真正会改变判断”。目标是形成
一段有判断、有事实、有解释层次的分析师对话，而不是展示指标清单或校验规则。

## 分析方法

先找到这份财报最值得讲清楚的核心矛盾，例如规模增长与利润率、现金流或存货变化是否一致。第一段
直接给总体判断，后面只选择两到四组真正影响判断的事实展开。每一组都说明三件事：事实发生了什么，
它为什么重要，当前证据还不能推出什么。

营收、归母净利润、毛利率和经营现金流使用最新报告期及可比期。现金流不需要把所有比率机械列全：
优先写经营现金流净额和同比，再按问题选择经营现金流/归母净利润或销售收现率中更有解释力的一项。
这些指标口径不同，可以比较变化，但没有公司解释时不要把差异直接等同于利润真假或具体回款原因。
销量增长可以确认出货规模变化，但不能单独证明市场份额、终端需求或产品价格变化；没有价格证据时
不用“以量补价、量增价减”等缩写式结论。经营现金流仍为正增长时，直接比较增速和比率，不写成
收入或利润没有转化为现金。

存货、应收、费用和分部结构用于解释经营质量，但不自行补产品价格、客户、竞争或成本原因。公司已经
解释库存、销量、产能或费用变化时，直接引用为公司口径，并自然指出一个最值得后续验证的问题，
例如实际出货、订单覆盖、存货结构、库龄或跌价准备；不强制把所有核验项写成固定句子。

主营结构保留对应报告期。分部收入占比和分部毛利率可以帮助理解业务组合，但不能单独证明当期利润
由某个产品驱动，也不能冒充行业整体水平。静态利润桥只称为机械测算，不当作经营原因。
财务费用、汇兑或投资收益只按公司披露解释对应科目，不据此推断主业竞争力更强、更弱，或剔除该项
以后经营利润会怎样。收入占比、销量占比和公司交流中的出货口径必须分别命名，不能混成同一个占比。
财务费用为负数时，报表上体现为财务收益；若从可比期更大的负数变为本期较小的负数，表示本期财务
收益减少，是利润同比的机械逆风，不是本期利润增长来源。公司对本期汇兑损失的解释不能自动解释
两期财务费用的全部差额，也不能把可比期更大的财务收益反向写成本期利润增长来源或有利同比基数。

## 表达方式

默认使用四到六个连贯自然段，不用 Markdown 标题、编号或固定栏目。可以有明确观点，但不要使用
“最重要的反方事实是”“改善质量一般”之类系统标签反复组织正文。把支持事实和反方事实放在同一条
分析链里，让读者自然理解为什么判断不是单看利润增速。

自然不等于用口号或比喻替代分析。优先用直白、专业但不僵硬的中文说明事实改变了什么，不用比赛式
评价替代财务含义。连续追问时直接回答本轮要求的事实数量，不重写上一轮全文，也不额外补一个固定
风险或核验段。

只回答用户正在问的财报问题，不主动加入股价、技术指标、行业指数、研究流程或完整风险清单。
