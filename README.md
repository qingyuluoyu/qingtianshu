# 清数智算 Agent Demo

这是一个后端优先的金融研究 Agent MVP：行情事实与指标由确定性代码产生，Hermes 负责解释、追问和使用经用户确认的记忆。

当前实现：

- 19 个主要海内外指数的可审计目录，支持历史日线和指标；
- 中日韩美与伦敦金盘中行情、数据延迟和当日分钟 K 线；中日韩使用当前分钟指数源，美股收盘后保留最近收盘快照，并用交易所日历识别节假日、午间休市与提前收盘；
- A 股热门板块接口，包含来源、市场时间、抓取时间和降级状态；
- A 股全市场广度接口 `GET /markets/breadth`：逐页汇总沪深京 A 股上涨、下跌、平盘家数，覆盖不完整或涨跌字段缺失时拒绝确认固定分类；
- 东方财富公司公告、新浪个股新闻和按股票代码过滤的东方财富股吧情绪；
- A 股财报全文分页抓取与长期保存：按报告期提取毛利、财务费用、汇兑、存货、回款、经营现金流、减值和非经常性损益的原文说明，并把“公司明确解释”与“独立验证因果”分层；
- 腾讯实时估值快照，以及东方财富 F10 的结构化报告期财务指标；
- 确定性财报质量分析：比较上一年度同类报告期的营收/利润增速、毛利率、净利率、经营现金流覆盖和资产负债率，保存支持证据、矛盾、复核点与静态毛利率敏感性；
- 利润与现金流驱动拆解：A 股读取完整利润表、资产负债表和现金流量表，美股读取 SEC XBRL 详细科目；同类报告期量化毛利桥、费用率、营运资金、销售收现和三类现金流，并把机械影响、可疑线索与未确认业务原因分别保存；
- A 股主营业务结构分析：保存产品、地区、行业收入和毛利构成，严格区分最新收入报告期与可用毛利参考期，并支持同口径年报/中报比较、集中度复核和研究报告接入；
- 英伟达接入 SEC Companyfacts 财务、10-Q/10-K/8-K 官方监管文件、腾讯美股估值与 Nasdaq 公司相关新闻；
- 中兴通讯、中际旭创和英伟达均有固定可审计同行估值样本；A 股同行进一步比较同报告期营收、利润、毛利率、现金流转换和主营构成，报告期不匹配不进入中位数，也不生成公司排名或高低估评级；
- 后台自动刷新行情、A 股信息、A 股财报全文、主营业务结构、A 股与美股财务估值、财报质量、利润现金流驱动、历史校准、研究报告、研究结果回填和 Market Pulse，并通过事件流通知网页；
- 用户、安全会话、自选股、关注理由、记忆候选/确认和 Agent Run 的 SQLite 存储；
- DeepSeek/ChatGPT 式多研究对话：新建、历史列表、连续上下文、重命名 API、归档和跨用户隔离；
- 统一“研究 Agent”工作区：Hermes 按当前问题检索实时证据、资料库和金融 Skills；同一页保存多段历史对话，并按市场区域或证券代码自动呈现对应 K 线，个股同时显示 RSI14、MACD、ATR14 和 5/20 日量比；多股票策略问题会保存并恢复全部研究对象，先展示多股比较摘要，用户指定单只后再加载对应日 K 线；
- 按正式 PRD 收敛为今日观察、我的关注、个股研究、AI研究、复盘中心、个人中心六个一级页面；透明选股移入 AI研究二级模式，资料库保留为资源入口，不再挤占一级导航；
- “今日观察”新增统一聚合接口 `GET /v1/today/overview`：首屏按高风险、到期任务、判断草稿确认和证据缺口展示最多 5 项，并同时返回上证综指、深证成指、创业板指、科创50、市场广度、成交、行业结构、与我相关的研究变化和盘前/盘中/盘后/非交易日状态；单个行情组件失败时，个人任务仍可独立返回。A 股指数在同一市场日期优先使用完整日线，不允许较晚的单点行情覆盖可计算收益和技术结构的历史；未完成来源与规则验收的自动事件不会伪装上线；
- “个人中心”诚实基础版：读取当前用户真实关注股票、股票研究空间、历史对话、资料库文档和待处理研究项数量，并展示会话有效期、Hermes 状态、数据健康和后台刷新状态；尚未实现的正式账号、会员计费、导出、账户删除、多设备和 BYOK 不做占位冒充；
- 个股 Agent 结构化回答与确认写回：每次股票研究在自然语言正文之外保存事实、证据推断、反方证据、待验证假设、信息缺口、失效条件、下一步核验和逐 Claim 引用；只有用户明确要求“形成/更新判断草稿”且 Run 完成时才创建候选，确认前不改变正式判断，确认后生成新的版本化判断，拒绝或版本冲突不会覆盖当前版本；
- “透明选股”双入口：AI研究二级页面可选择经营改善、相对行业增强、估值约束和回撤待复核四类透明模板，自然语言也可解析 PE、PB、市值、ROE、营收/净利润增速、行业和市场范围；确定性引擎执行筛选，逐只展示命中原因、交易日、财务报告期、缺失项和边界，不计算综合分或买卖信号；候选可保存为研究线索，或直接进入该股票唯一的长期 Agent 对话继续核验；
- “李总策略”独立执行全A股确定性筛选：先发布并按同一请求日复用最近完整交易日的全市场名单和市值快照，再对市值严格大于150亿元的股票预判上市后量价窗口；只有量价历史客观不足时才直接保存为数据不完整，不消耗逐股深度请求。预判按 A 股约 242 个交易日/年的市场日历并增加节假日缓冲，避免把只有 377 条行情的近期上市股票误送入 380 日深度规则。上市未满五年不会被当成 ROE 必然缺失，因为公开财务数据可能包含上市前年度，必须实际查询后判定。其余股票按历史完整性、既有数据可得性和市值分批补齐 ROE、股东、复权日线和真实涨跌停价。年度 ROE 以 Tushare 为主；若某一必需年度的直接值缺失，仅使用已有的东方财富 F10 结构化 Provider 补该年度，不覆盖 Tushare 已有值，并把公告日、来源 URL 和补充原因写入规则证据。网页和 Agent 分开说明全市场名单、可深度核验、深度处理进度、量价历史不足和候选数量，不再把名单状态覆盖率冒充深度规则完成率；支持在同一问题中解析多个全市场公司名称并逐股回答，用户页面会清理内部状态枚举和供应商错误。后台批次通过事件流自动刷新透明选股页。日线、复权和涨跌停价在同一次逐股同步中统一预留 700 个市场交易日，减少长期停牌造成的假性历史不足，不额外增加接口调用次数；旧短窗口缺口只按数据窗口版本重算一次；
- “我的关注”研究资产页：`GET /v1/stock-workspaces` 返回当前用户全部持仓、关注和已结束股票空间；页面支持关系、高/普通/低优先级、暂停和等待数据筛选，以及单项关系修改、暂停、结束和恢复。列表展示正式判断版本、最新变化、下一事项和行情；已结束空间继续保留原 `workspace_id`、判断、任务与历史。持仓事实未配置时不展示虚构数量、成本或盈亏；右侧详情仍可切换分时、日线和周线，并进入同一股票研究空间或 Agent；
- “个股研究”与股票研究空间：第一屏先展示股票关系、当前判断、最多三条重要变化和最多三项待处理；研究概览用五栏证据地图集中展示支持、反证、风险与失效条件、信息缺口和下一证据，并可直接进入完整证据或复用唯一研究对话继续核验；随后按研究概览、AI研究、数据与证据、任务与操作、历史与复盘五个标签渐进展开；底层继续复用每用户每股票唯一会话、近一年 K 线、估值、财务质量、利润现金流、股东、券商预期、官方事件、公告新闻、社区弱证据和七阶段研究状态；数据与证据页按公司经营、财务质量、行业与相对表现、估值、技术状态、风险事件六维显示 sufficient/partial/insufficient/unavailable 覆盖状态，每个维度再拆分为原始数据、系统计算、Agent 解释和缺失项四层，保留来源与时间；Agent 解释优先读取绑定会话，必要时仅回收同一用户、同一证券的最近结构化历史；研究阶段只有在 Run 完成、输出守卫通过、核心证据可用、对应覆盖充分且来源可追溯时才会完成，否则明确显示“待复核”及原因；
- “复盘中心”白盒页：新增数据来源→采集校验→金融数据库→算法与 Skills→Hermes Agent 的后端流程图，并展示回答中的当前问题、实时证据、个人上下文和回答约束；不展示密钥、内部提示词或供应商故障；
- 研究行动与观察条件：吸收 Rongxian `ResearchItem` 的生命周期思路，把自选股报告、证据变化、回撤波动、MA20、量能、用户关注理由和资料缺口转换成“已达到复核条件 / 待补证 / 继续观察”，持久化快照并同步进用户资料库；该功能只决定下一步核验什么，不生成买卖信号；
- 用户观察任务：与后台 EvidenceTask 和系统 ResearchAction 分开保存，只有用户确认后才创建；支持待处理、处理中、等待数据、完成、忽略、取消和重开，完成必须填写结果或引用证据，编辑与状态变化均保留版本历史并按用户隔离；
- A股分析师一致预期与研报跟踪：保存券商评级分布、A/E 每股收益预测和近期研报元数据；只有存在历史快照时才计算同财年 EPS 上修或下修，并同步报告覆盖机构变化；预测不是公司指引，评级不是交易建议，目标价不进入证据包；
- 独立“资料库”页面：右侧集中查看全部通用/个人资料，支持 TXT/Markdown/CSV/JSON 入库、删除、中英文相关性检索、个人工作区副本和 Hermes Prompt 引用；左侧不再常驻资料卡片；
- 每用户独立工作区、确认记忆文件和自选股文件；
- HttpOnly、SameSite=Strict 的匿名个人会话；原始令牌不落库，SQLite 只保存 SHA-256 哈希，私有 API 强制校验会话归属；
- 网页记忆确认闭环：对话提取的偏好以卡片展示，用户可确认保存或暂不保存；待确认卡片在刷新后会恢复，只有 confirmed 记忆会进入后续 Agent Prompt；
- 收益率、MA20/MA60、20 日年化波动率、60 日最大回撤，以及 RSI14、MACD(12,26,9)、20 日布林带、ATR14 和 5/20 日量比；
- 市场、透明选股、通用研究、自选、单股研究、财报质量、利润现金流驱动、主营业务结构、股东结构、分析师一致预期、重要事件脉络、A股财报全文证据、长期变化跟踪、研究优先级、研究行动、研究结果复盘、A股信息、SEC 监管证据、财务估值、牛熊证据、条件展望、文章、记忆和图像研究等二十五个 Hermes-compatible Skills；
- 通用研究 Skill 与连续上下文组装；用户追问“那它的风险呢”时会继承证券标的，追问“那主要风险是什么”时会继承美股等市场区域焦点；
- 参考 TradingAgents 的专业角色分工，形成行情、新闻、情绪、基本面、分析师预期、同行、多空与风险委员会七模块确定性分析板；
- 参考 Rongxian 的研究清单、候选跟踪和结果回填，为个股生成 3/5/10 个交易日复核计划，并只用已存复权日线持续回答“之前的研究后来怎么样”；
- 未来 5—20 个交易日的透明条件展望：三种情景、关键价位和失效条件；固定价格规则使用五年复权日线做无前视走查和最近 30% 样本外检验；
- 低频高密度 Market Pulse 行情文章：质量评分、四小时最小间隔、结构指纹去重、24 小时最多三篇；
- 中兴通讯、中际旭创和英伟达默认研究组合；服务器预生成最新研究报告，网页可直接点击阅读；
- 连续研究变化归档：相邻报告会比较技术状态、回撤、波动、情绪、财务报告期、财报质量、利润现金流驱动、分析师一致预期修订、事件和七模块覆盖，并保存为可被后续对话检索的长期资料；
- 研究结果归档：每个研究时点按 T+3/T+5/T+10 保存到期或未到期状态、阶段路径、最大上行/下行和条件触发；不计算荐股胜率或策略收益；
- Yahoo 历史行情在读取时同步写入 SQLite `market_bars`，日线保留 `adjusted_close`，让后续复盘只依赖已落库数据；
- 市场短文和个股研究合并为按时间倒序、可滚轮浏览的洞察流；原始供应商异常只保留在后台诊断中；
- 每分钟执行确定性数据质量审计，覆盖分钟线、交易日历、事件信息、财务估值、详细三表、财报质量与利润驱动快照、同行样本、研究报告和后台任务；前端只展示简化健康状态；
- A股全市场快照覆盖沪深京 5,528 只股票，同时保存上涨/下跌/平盘家数、总成交额与分交易所成交额、涨跌幅中位数/四分位和固定 ±3% 分档；成交额明确不等于资金净流入，同口径历史从接入日起逐日积累；
- A股精确行业证据：按公司行业名称检索或通过明确映射连接中证官方指数，保存指数定义、历史日线、官方样本名单和权重；个股涨跌归因按目标交易日对齐公司、代表性指数和行业指数，并计算公司相对行业涨跌。系统并发抓取全部成分复权日线，覆盖完整时给出上涨/下跌/平盘家数、涨跌幅中位数和固定广度分类；按官方权重快照估算成分贡献并保留与官方指数收益的对账差。当前已实测通信设备 `931160`、电池 `931719`、中证白酒 `399997`、中证银行 `399986`，跨分类体系映射会明确提示口径边界；
- 对话质量复盘：按用户隔离保存聊天与 Run，确定性检查守卫回退、行级修复、超过 30 秒的慢回答、相邻回答高相似、可见引用缺失和反复出现的数据需求；结果落库、写入个人工作区并显示在“复盘中心”；
- Hermes 私有守卫流式输出与分段耗时：独立桥接 Hermes `AIAgent` 的真实 delta，按用户和随机 `request_id` 通过私有 SSE 增量返回；`guarded_cumulative_stream_v3` 分开处理单句硬错误、累计上下文和全文完整性，当前报价等必要时间锚点出现前不展示可能误导的旧日线开场，随后按句持续增长，最终答案再执行完整守卫并原位替换。服务保存首模型片段、首个安全可见片段、原始 delta、可见更新、拦截/暂缓段落以及路由、证据、模型、守卫和总耗时；断线重连会重放累计安全草稿，终态自动结束，桥接失败回退原 Hermes CLI；
- 市场参与面证据守卫：成交量、成交额、量能或量比只能描述交易活跃度，不能直接证明上涨参与面或市场覆盖范围；全市场广度必须引用涨跌家数，板块内部参与面必须引用成分覆盖和内部涨跌家数；
- `economy`、`deep`、`vision` 三层模型路由；
- PNG/JPEG/WebP 图片安全上传：解码、EXIF 方向处理、重新编码去元数据、大小/像素限制、个人工作区隔离和 `vision` 路由；
- 普通研究对话保留两阶段即时回答：先返回服务器确定性证据摘要，再由 Hermes 原位补充深度解读；“诊大盘 / 诊个股”直接等待 Hermes 针对当前问题生成，不再让固定摘要造成“每次回答一样”的错觉；对话数据库不会生成重复消息；
- 确定性 preview 模式、可见的“AI 深度解读”开关，以及模型输出数字/目标价/概率守卫。
- 对话可直接识别“中兴通讯为什么大跌”等中文公司名问法；未识别对象时返回可操作的补充提示，不再直接报 `422`。实时证据刷新失败时，默认标的会使用服务器最新预生成报告证据。
- “美股为什么收盘跌了”会同时组合指数价格事实与近期市场资讯驱动；资讯会在对话中即时刷新并入库，后台也会预先刷新七个市场范围。

### 结构化回答与判断确认 API

`stock_research` 对话响应和历史消息 `metadata` 会包含
`structured_answer`。其主要字段为：

- `answer_summary`
- `confirmed_facts`
- `evidence_based_inferences`
- `hypotheses_to_verify`
- `counter_evidence_and_risks`
- `information_gaps`
- `invalidation_conditions`
- `next_evidence_tasks`
- `conclusion_boundary`
- `citations`
- `candidate_writebacks`

引用和候选写回会持久化到 SQLite；公开响应不会返回 `user_id`、
`workspace_id`、`conversation_id`、内部 `source_key` 等字段。当前 R1
首先开放版本化“当前判断”写回：

- `GET /v1/ai-writebacks`
- `GET /v1/ai-writebacks/{candidate_id}`
- `POST /v1/ai-writebacks/{candidate_id}/confirm`
- `POST /v1/ai-writebacks/{candidate_id}/reject`

普通问题不会产生判断草稿。可以明确询问：

> 分析中兴通讯当前支持证据、反方证据和失效条件，并形成判断草稿，供我确认，不要直接修改正式判断。

Agent 失败、守卫未完成或只返回 preview 时不会创建候选。确认时若正式判断
已经变化，接口返回 `409` 并把旧候选标记为 `stale`。当前还没有开放任务、
操作计划和正式复盘的通用 AI 写回，这些对象必须等各自领域模型完成后再接入。

首次打开页面会自动创建匿名个人会话，不需要注册。默认数据写入项目下的 `data/`；可通过 `QINGSHU_DATA_DIR` 改到独立持久化目录。

## 服务器后台运行

服务启动后会自动执行多类后台任务，不需要用户点击：

- 每 30 秒刷新中日韩美和伦敦金分钟行情并写入 SQLite；
- 每 10 分钟刷新默认 A 股及全部用户自选股的公告、新闻和社区情绪；
- 每小时发现并保存默认 A 股及全部用户自选股最近三份财报全文，内容不变时跳过重复下载，并刷新原文原因摘录和长期通用资料；
- 每小时刷新默认 A 股及全部用户自选股的产品、地区、行业主营构成和同口径比较，并写入长期通用资料；
- 每小时刷新默认 A 股及全部用户自选股的股东户数、十大股东和股权结构快照，并写入长期通用资料；
- 每小时刷新默认 A 股及全部用户自选股的券商评级分布、A/E 每股收益预测、近期研报元数据与历史修订边界；
- 每小时刷新 A 股实时估值与结构化财务报告期；
- 每小时刷新英伟达的腾讯美股估值、SEC 财务与 10-Q/10-K/8-K；
- 每小时为默认研究标的和用户自选股刷新同类报告期财报质量分析，并写入长期通用资料库；
- 每小时基于已落库详细三表刷新利润、费用率、营运资金和现金流驱动分析，并写入长期通用资料库；
- 每小时刷新三只默认标的及其九只固定同行的估值快照，并为 A 股固定同行刷新同报告期经营和主营构成快照；
- 每 6 小时用五年复权日线刷新 5/10/20 日走查校准；
- 每 30 分钟为中兴通讯、中际旭创和英伟达刷新服务器研究报告；
- 每 30 分钟扫描历史研究时点，并按 T+3/T+5/T+10 回填研究条件和价格路径；
- 每 10 分钟预先刷新美股、A 股、港股、日股、韩股、欧股和伦敦金的市场驱动资讯并入库；
- 每 30 分钟检查一次 Market Pulse 发布条件，符合质量、变化和频率门槛后自动发布，并通过 `/events` 事件流通知网页。
- 每分钟执行数据质量审计并写入 SQLite；详细检查只通过 `/system/data-health` 提供给运维，网页只显示“数据已连接”或“部分数据同步中”。
- 李总策略使用独立后台线程：先建立全市场稳定市值快照，再按 `LI_ZONG_UNIVERSE_BATCH_SIZE` 分批补齐高市值股票的多年规则数据；每批完成后等待 `LI_ZONG_REFRESH_SECONDS` 再继续，不阻塞实时行情和其他后台任务。

```bash

```

行情数据库保存在 `qingshu-data` volume。容器默认使用无需模型费用的确定性 preview；生产 Hermes Provider 应通过云端密钥管理和独立 Agent Worker 接入。

## 开启 Hermes

复制 `.env.example` 中需要的变量到你的进程环境。最小方式：

```bash
export HERMES_ENABLED=true
```

然后在 `/chat` 请求里传：

```json
{
  "message": "分析我的自选股",
  "model_tier": "economy",
  "execute_agent": true
}
```

模型路由读取：

- `HERMES_ECONOMY_PROVIDER` / `HERMES_ECONOMY_MODEL`
- `HERMES_DEEP_PROVIDER` / `HERMES_DEEP_MODEL`
- `HERMES_VISION_PROVIDER` / `HERMES_VISION_MODEL`

未设置时由 Hermes 当前配置决定。密钥由 Hermes 或进程环境管理，本项目不会读取、打印或复制密钥。

一键启动不会假设特定供应商：检测到 `HERMES_BIN` 可执行文件时才启用 Hermes，模型和 Provider 继续由用户自己的 Hermes 配置或环境变量决定。密钥只由 Hermes 或进程环境读取，不写入项目。

`HERMES_BIN=hermes` 会按当前进程的 `PATH` 解析，不要求写本机绝对路径。流式回答会从 Hermes 控制台脚本或启动包装器识别其虚拟环境 Python，并保留虚拟环境入口；只有非标准安装无法自动识别时，才需要设置 `HERMES_PYTHON_BIN`。应用不会读取或复制 Hermes 密钥。

Hermes 返回后会经过 `deterministic_numeric_and_policy_guard_v2`：守卫理解“涨 / 跌 / 回撤”的语义方向、合理四舍五入和由确定性证据计算出的均线距离等派生值。大盘回答只使用模型实际收到的当前市场、当前问题证据校验，不会让其他市场数字或上一轮助手措辞成为可信事实；用户输入中的数字也不会因此放行。守卫仍拒绝证据外数字、反向改写、目标价、未来涨跌概率、收益保证、浪型判断以及 BUY/HOLD/SELL 指令，并拦截原始字段名、后台状态、供应商名称和数据源故障。若回答只包含少量不受支持的句子，系统会删行后再次完整验守，尽量保留其余针对性模型回答；涉及策略禁令、语义冲突或无法安全修复时，才退回确定性摘要。原始被拒文本只留在该用户 Run 目录用于诊断。

“诊大盘”会直接执行 Hermes，而不是先把固定市场模板当成最终回答。后端按当前问题区分趋势反转、量能资金、板块轮动、涨跌原因和市场风险五类焦点，只保留该问题需要的指标、板块、实时资讯、已确认用户记忆和 `market-brief` Skill。大盘 Prompt 固定带入“证据层级、市场因果、趋势风险”三份通用资料；连续追问只保留最近用户问题并继承市场范围，不把上一轮模型回答重新当作写作模板。若模型超时，确定性摘要也会按本次问题焦点回答，不再退回同一份全景模板。

多模态请求使用 Hermes 的 `chat -q --image` 路径。网页先通过 `POST /me/uploads/images` 上传图片，对话只传服务器生成的 `image_id`；客户端不能传本机路径。后端会验证图片归属，Hermes 只能读取当前用户专属工作区内的已消毒副本。图像回答通过显式最终答案协议去除 CLI 推理文本，然后再进入金融数字和策略守卫。

## 数据和诚实边界

- 指数/个股历史日线：Yahoo Finance Chart 公开接口并同步写入 SQLite；中国、日本、韩国首页分钟指数使用东方财富当前分钟接口，美股使用最近盘中/收盘分钟快照；伦敦金使用新浪 XAU 分钟价格聚合五分钟 OHLC；
- A 股公司公告：东方财富公告接口；个股新闻：新浪财经；社区情绪：东方财富股吧；
- A 股财报全文：交易所公告聚合的公司报告正文，按正文页完整保存；原文中的“主要因、由于、导致”等公司解释会单列，但不视为独立因果证明；
- A 股估值：腾讯完整行情；结构化财务：东方财富 F10 主营财务指标与利润表、资产负债表、现金流量表详细科目；
- 美股估值：腾讯美股完整行情；英伟达结构化财务、详细 XBRL 科目与监管文件：SEC EDGAR Companyfacts 和 submissions；
- 美股公司新闻：Nasdaq 公司资讯聚合，并保留原发布者和原文链接；
- A 股板块：东方财富公开板块排行接口为主源，失败时降级到新浪行业板块；
- 新浪降级源不提供主力资金、上涨/下跌家数和明确市场时间，接口会保留空值并返回 warning；
- 免费接口无 SLA，可能限流、WAF 或修改字段；
- 上游失败且有缓存时返回 `is_stale=true`；没有缓存时返回明确 warning/502；
- 当前已有公告、新闻、社区样本、结构化财务、估值、固定同行样本、A股券商一致预期与近期研报元数据，以及默认行业的官方指数、样本广度和静态贡献估算；仍缺全行业/概念完整映射、历史样本变更档案、估值历史分位、研报全文与长历史修订序列、完整行业供需和机构持仓，因此不构成完整投资建议；
- 历史校准只覆盖固定价格规则：每个信号只使用当时及以前数据，最近 30% 时间段作为保留样本；历史上涨占比不会被包装成未来概率；
- 热门板块资金字段只按数据源口径展示，不解释为真实资金意图；
- 系统不生成目标价、胜率或确定性收益承诺。

## 低频实时文章调度

服务器内置后台任务会自动做发布评估。`scripts/publish_market_pulse.py` 只是开发人员需要单独验证文章逻辑时使用；系统只有在证据质量达标、距离上一篇至少四小时、市场结构指纹变化且未超过 24 小时三篇上限时才真正生成文章。


需要后台模型润色时同时设置 `HERMES_ENABLED=true` 和 `BACKGROUND_USE_HERMES=true`。生产版应把后台任务迁移到独立 Worker/任务队列；当前实现使用一个通用调度线程和一个独立李总策略线程，属于可运行的 MVP 编排，不等同于分布式任务队列。
